Mallard Guard client enforcement

To use your client settings as the server's enforced values, copy
config/mallard_guard/client.toml here as client.toml. On a dedicated server,
copy the client.toml from your Minecraft installation to this server's
config/mallard_guard/enforce/ folder. Enable enforcement in game as an OP.

When this template exists, it supplies the Enforce screen's values.
For Punchy presets and motion, also copy mg_punchy/config.toml into enforce/mg_punchy/config.toml.
Applying changes in that screen also updates the copied files.
The categories marked Don't Enforce still start with these values,
but players can edit them afterward. The original client file is not changed.
